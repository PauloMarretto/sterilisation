A aplicação simples tem a função de registrar os ciclos de esterilisação.

App em HTML/CSS, javascript et node.js para acesso ao DB

A estrutra de PATH está configurada até o momento somente para Windows.

Com 4 telas:

Registro de Ciclo
Autoclaves
Responsável (têcnico)
Relatório
A base de dados e em SQLite
